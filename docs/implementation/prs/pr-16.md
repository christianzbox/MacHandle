credential namespaces, signed sandbox/Keychain behavior and private destination sharing
without broadening scopes. Verify calendar.app.created classification in the actual Google
console. Its permission includes editing/deleting events in app-created calendars; edits
on selected Apple sources update the saved Google event identity in the one-way mirror.

source change stream and complete workspace/network state; sessionActive AND awake gate

restoration conservatively. Never run source reads or ask OS permissions merely at launch.

Require full exact destructive-plan approval. If account setup or supported privacy proof
is missing, preserve honest disabled states and record remaining owner/trigger gates;
synthetic UI is not end-to-end provider acceptance. Do not bypass sandbox/privacy checks.

roadmap/progress/coordination and prepare package 17's focused brief. Run all three gates,
commit/push and open one review PR; stop before merge or release.
