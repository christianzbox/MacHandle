## Implementation and acceptance

[ADR-0015](../../architecture/decisions/0015-sqlite-persistence.md) records the schema,
filesystem/backup decisions, alternatives, limits and recovery owners.

| Requirement | Implementation | Evidence / limit |
| --- | --- | --- |
| Versioned migrations | Application ID, exact manifest, v1 identity/mappings then v2 operations/state/checkpoints; transactional upgrades | Frozen-v1 migration, rollback, newer/unexpected schema and identity mismatch fixtures |
| Resource/event mappings | Bound store/install/client/account, unique opaque source keys and stable remote event IDs | Restart/isolation/duplicate/foreign-key tests; candidates require remote verification |
| Fingerprints/state | Digests, observed versions, retained tombstones, paused/recovery-required status | Conditional transition and no-resurrection tests; no event content or tokens |
| Pending operations | Prepare durably; commit unknown before future dispatch; atomic result/completion | Commit-failure and restart tests; no replay of unknown outcomes |
| Checkpoints | Revision compare-and-swap; unresolved operations block advancement | Conflict/rollback fixtures; not source completeness or deletion authority |
| Local files | Explicit create/resume, owner-only files, nofollow checks, separate local lock, bounded errors | Missing/corrupt/unsafe/replaced files and writer exclusion; no cross-Mac guarantee |
| Boundaries | Separate SDK SQLite target, no provider/domain dependencies, private SQL | Dependency guard and twelfth compile-fail probe; app links but never opens the store |

Fifteen new synthetic storage tests bring the suite to 140 Swift plus 13 Python tests.
Standard staged/final-head and hosted results belong in progress and the review PR.
Databases are generated under private temporary directories and removed; no binary
fixture, provider content, real token or live account is accessed.

Integration/restore authority is deferred to packages 12/14: trusted account binding,
remote verification and durable-ID bridging into the internal client, ambiguous-outcome
recovery, retention/backup and cross-Mac writer transfer. Trigger: authorization of those
packages plus their live activation gates. Missing data never grants cleanup/recreation.
The public storage API records observations; it cannot authenticate remote ownership.
No planner, executor, source writes, MCP, background sync or database startup is added.
