Implement the bounded stdio protocol foundation, initialization/version negotiation,
typed tool registration/schemas, errors, lifecycle and mock tools. Verify current official
MCP requirements and the intended client/version matrix before choosing dependencies.
Separate transport and protocol from domain/provider modules. Reserve stdout for protocol
frames; use content-free bounded diagnostics, cancellation and controlled shutdown.
Test malformed/oversized messages, unsupported versions, errors and interoperability.

Stdio/process presence, client-supplied names and resource text are not authenticated
identity or approval. Keep pairing/identity/policy activation gated until its owning
package; no Calendar mutations, live personal data, remote listener or administrative
sync/permission interface is exposed. Mock tools must remain synthetic. Signed broker/
helper IPC, sandbox/process entitlement and distribution feasibility remain explicit
Apple runtime gates. Do not bypass them to demonstrate a working transport.

Google synchronization must remain independent. Package 16's account/private-destination/
signed/live acceptance follow-up remains open in its brief and does not block unrelated
synthetic MCP protocol work, but it must not be marked complete by this package.
No accounts, release enrollment, Apple review submission or security audit purchase is
implied. Update ADRs, brief/roadmap/progress/coordination, prepare package 18's focused
brief, stage/review, run all three gates and open one review PR. Stop before merge.
