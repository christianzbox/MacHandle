Implement trusted create/update/delete proposal handling with explicit validation and
human-readable exact diffs, locally issued confirmation, expiration, single-use consumption
and content-minimized audit. Bind each approval to connection, policy generation, exact
resource/arguments, current preconditions and reviewed fields. Resource text and transport
retries cannot approve or replay mutations. Consume approval atomically with admission;
revalidate immediately before mock provider dispatch and report cancellation/unknown outcomes
without promising rollback. Use mock writers only; no EventKit source writes or Google
write grants. Existing Google sync deletion approvals are a separate authority boundary.

Test replay, altered fields/target/connection, stale versions, expiry, revoked sessions,
policy changes during review/execution and concurrent confirmation. Preserve the package 19
signed-peer/native pairing/runtime gate; mock approval contracts do not close it. Determine
required local review presentation from actual app contracts and record any unavailable
runtime wiring with owner/revisit trigger. Update architecture/ADRs and all handoff documents,
prepare package 21's brief, stage/review and run all three gates, then push/open one PR.
Stop for user review before merge, release or implementing real Calendar mutations.
