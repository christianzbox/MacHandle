# Work package 11 — Pure reconciliation planner

Legacy specification ID: PR-11. Planned only; verify work package 10's actual GitHub
merge and obtain new authorization before implementation. Read [coordination](../pr-coordination.md),
[progress](../progress.md), [roadmap](../pr-roadmap.md#pr-11),
[ADR-0014](../../architecture/decisions/0014-google-destination-client.md),
[ADR-0015](../../architecture/decisions/0015-sqlite-persistence.md), specification
[PR-11](../../product/master-spec.md#pr-11--pure-reconciliation-planner) and
[§7](../../product/master-spec.md#7-google-calendar-synchronization).

Implement a deterministic pure planner producing create/update/delete/no-change/conflict/
manual-intervention outcomes from explicit source coverage, destination observations,
validated mapping candidates, privacy policy and stable fingerprints. Keep it independent
of SQLite, EventKit, HTTP, Keychain, UI and side effects. Add domain contracts only when
needed. A persisted checkpoint is not proof of complete source reads or remote ownership.

Require known identity, source completeness, current selections/policy and verified
remote evidence before destructive proposals. Missing/corrupt state, unknown operations,
revoked access, ambiguous occurrence identity and incomplete pagination must suspend
unsafe reconciliation. Repeated unchanged inputs produce no writes; privacy reductions
remove previously shared details. Preserve stable occurrence/operation identity and
surface conflicts rather than silently replacing user changes. No proposal authorizes
execution or mass deletion by itself.

Use synthetic deterministic examples covering idempotency, partial snapshots, missing
mappings, changed versions, unknown outcomes, policy changes and privacy reduction.
Do not dispatch providers, activate Google, wire database records into live capabilities,
implement package 12 executor or package 14 recovery, or change Apple resources.
Run all three repository gates, update brief/roadmap/progress/coordination/ADRs, prepare
package 12's brief and open one PR for review. Stop before merge or the next package.
