Implement a deterministic pure planner producing create/update/delete/no-change/conflict/
manual-intervention outcomes from explicit source coverage, destination observations,
validated mapping candidates, privacy policy and stable fingerprints. Keep it independent
of SQLite, EventKit, HTTP, Keychain, UI and side effects. Add domain contracts only when
needed. A persisted checkpoint is not proof of complete source reads or remote ownership.

Require known identity, source completeness, current selections/policy and verified
remote evidence before destructive proposals. Missing/corrupt state, unknown operations,
revoked access, ambiguous occurrence identity and incomplete pagination must suspend
unsafe reconciliation. Repeated unchanged inputs produce no writes; privacy reductions
remove previously shared details. Preserve stable occurrence/operation identity and
surface conflicts rather than silently replacing user changes. No proposal authorizes
execution or mass deletion by itself.

Use synthetic deterministic examples covering idempotency, partial snapshots, missing
mappings, changed versions, unknown outcomes, policy changes and privacy reduction.
Do not dispatch providers, activate Google, wire database records into live capabilities,
implement package 12 executor or package 14 recovery, or change Apple resources.
Run all three repository gates, update brief/roadmap/progress/coordination/ADRs, prepare
package 12's brief and open one PR for review. Stop before merge or the next package.

## Implementation and acceptance

Implemented on `codex/reconciliation-planner` in [GitHub PR #12 — Add pure deterministic reconciliation planning](https://github.com/christianzbox/MacHandle/pull/12)
after user authorization on 2026-10-27.
Prerequisite GitHub PR #11 merged at `4a5ad09a22be45b681c46675d756500603a58d8c`,
20:05:30 UTC. [ADR-0016](../../architecture/decisions/0016-pure-reconciliation-planner.md)
records alternatives, contracts, conservative deletion gates and integration owners.

| Requirement | Implementation / evidence |
| --- | --- |
| Pure desired-state comparison | Isolated SyncPlanning target; no provider or persistence dependencies; app never invokes it |
| Determinism/idempotency | Versioned SHA-256, sorted proposals, stable occurrence anchors, convergence and permutation tests |
| Privacy projection | Availability defaults, explicit per-field detail, replacement clears, fetched/unauthorized distinction |
| Safe reconciliation | Completeness/freshness/scope/mapping gates, version/content conflicts, unknown-outcome blocking |
| Delete/manual outcomes | Cancellation or separately verified absence, horizon protection, every delete requires confirmation |
| Recovery boundary | Missing mappings/destinations and tombstones never authorize silent recreation |

Eighteen new synthetic tests bring totals to 158 Swift + 13 Python tests and thirteen
compiler rejection probes. Standard gate evidence is recorded in progress and the review
PR. No trusted provider/storage adapter, execution authority, remote call, database startup
or source write is implemented. Existing local-cache source reads cannot be relabeled as
verified freshness to activate planning. Packages 12–14 own those integration gates.
[Package 12](pr-12.md) is a planned brief only. Stop for user review.
