## Scope and contracts

Implement CalendarReading through the isolated Apple provider: bounded event reads,
normalized occurrences, selected-calendar filtering, availability and explicit source
snapshot observation/coverage. Keep CalendarWriting separate and unimplemented.

Application discovery selections are values, not grants. Add a trusted read path with
explicit local selection, current real OS observations and operation/field policy;
never reuse synthetic preview authorities. Revalidate policy after suspensions and
before returning filtered data. Missing/empty selections must never become a nil
EventKit calendar predicate (which means all calendars). Refetch selected IDs and
reject unresolved/ambiguous or revoked resources.

Use finite requested windows and document EventKit's range cap. Preserve recurring
original anchors, all-day civil-date/exclusive-end and timezone semantics, cancellations,
occupancy and unknown revision/freshness. Do not infer upstream completeness from local
fetch success or authorize destructive reconciliation from missing data. Availability
must exclude titles, locations, notes and identifiers outside its authorized contract.
