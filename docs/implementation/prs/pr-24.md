Implement independent Contacts opt-in and field-minimized native discovery/search/detail contracts,
exact container/record identity and explicit supported subsets. Use public Contacts APIs only;
macOS permissions do not imply an iOS limited-contact grant. Unified identities and provenance must
not leak fields from unselected records/containers. Search must not infer hidden fields. Default
denied, current OS/policy/selection, revocation and incomplete-read behavior remain enforced.

Add scoped MCP read tools behind existing signed-peer/native-pairing activation gates, with bounded
responses and no caller-selected authority. Use synthetic contacts and no personal account data.
Keep Contacts independent of Calendar/Reminders/Google. No writes: management belongs to package 25.
Do not activate existing mutation factories, broaden Reminder scope or start Notes work.

Validate minimization, hidden-field search, unification/subset ambiguity, foreign IDs, denied/revoked
access, cancellation/late results and protocol behavior. Record decisions/alternatives, actual evidence,
owned limits, brief/roadmap/progress/coordination and the next brief. Stage/review, run all three gates,
commit/push and open one PR. Stop for review without merge, auto-merge or release.
