exact local review, heightened deletion acknowledgement and current OS/policy/record/field checks.

must never select a mutation target. Package 24 read snapshots expose unknown mutation revisions:
establish a supported observed-state/conflict path before allowing writes. Never infer approval from
read handles, saved candidates or caller flags. Contacts notes remain unavailable without the ADR's
entitlement and consent gate.

Verify current public CNSaveRequest behavior, container rules and conflict limits from Apple sources.
Define dedicated durable intent/receipt/uncertainty containment, replay/expiry/revocation handling and
safe restart behavior; do not reuse Calendar or Reminder journal authority. Keep signed peer/native
pairing and provider conflict acceptance closed where evidence is unavailable. No actual contact
write is authorized for development tests; use synthetic providers and in-memory public values.
Real runtime validation needs separately authorized isolated accounts and signed setup.

Test unauthorized fields, stale/foreign/moved/linked targets, delete confirmation, cancellation before
and after dispatch, unknown outcomes, restart and unchanged unrelated records. Preserve independent
Calendar/Reminders/Google policy and existing settings. Record decisions, owned limitations, acceptance,
progress, coordination, roadmap and prepare package 26's Notes feasibility brief only. Stage/review,
