Implement opt-in launch at login, bounded periodic reconciliation, EventKit change signal
debouncing, sleep/wake/network recovery and pause/resume. Use explicit lifecycle/clock/
network dependencies and structured concurrency. Enforce no overlapping jobs; signals
request fresh observation, never grant mutation authority or reuse a stale preview.
Standby must not run mutations. Stop scheduling and drain before writer handoff;
unresolved operations require recovery and cannot be retried as fresh writes.

Preserve default-deny live composition, exact destructive approval, account/field/source
freshness and current writer checks. Google sync remains independent of MCP. There is no
promise of operation while the Mac is asleep, off or the user has quit. Resolve what runs
when the window closes versus application quits and document supported login behavior.

Test coalescing, cancellation, suspend/resume, reconnect, rate limiting, revocation,
standby and handoff races using synthetic dependencies. Measure idle resource usage with
a reproducible observation and state its limits; do not infer battery or real service
performance from fake-clock tests. Do not activate Google, add real accounts or request
permissions at launch to satisfy background acceptance.

Update focused acceptance, architecture/ADRs, roadmap/progress/coordination and package
16's brief. Review/stage, run all three repository gates, commit/push and open one review
PR with exact evidence. Stop before merge, onboarding implementation or release.

## Implementation and acceptance

[ADR-0020](../../architecture/decisions/0020-background-synchronization.md) records the
architecture, alternatives, measured idle sample and explicit live limits.

| Requirement | Implementation and scoped evidence |
| --- | --- |
| Launch at login | Native Settings action and SMAppService adapter; status-only startup, approval-required/error handling, no silent re-registration; synthetic service tests. |
| Periodic reconciliation | Internal monotonic scheduler, five-minute default, bounded interval and no catch-up burst; fake-clock cadence and idle harness. |
| EventKit changes / debounce | Existing provider change stream accepted without provider objects; coalesced two-second quiet period with ten-second cap; stream/clock tests. |
| Sleep/wake/network | NSWorkspace/NWPathMonitor adapter with complete state snapshots; generation cancellation, stale callback rejection and restart from fresh observations. Synthetic adapter and scheduling tests only. |
| Pause/resume / no overlap | Drain old worker before replacement or ownership handoff; default standby/paused, no timer while suspended; cancellation-ignoring and transfer-race tests. |
| Safe retries / recovery | Only known preparation failures retry with preserved floor and bounded budget. Existing executor retains all authority checks; unknown/pending journal blocks automatic replay. |
| Idle usage | Actual optimized coordinator sampled paused/enabled-idle; zero additional jobs and CPU/RSS observations recorded in ADR-0020. Whole-app energy and real sleep/network acceptance remain open. |
